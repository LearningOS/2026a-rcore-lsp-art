## 实现内容

spawn 直接装入目标程序，建立父子关系并加入就绪队列。调度器选择 stride 最小的进程，每次按优先级增加步长；默认优先级为 16，小于 2 的设置返回错误。保留时间查询和匿名内存映射，并在 exec 时更新堆边界。

## 问答

1. 8 位整数中 250+10 会变成 4，普通比较会再次选择 p2，而不是应当运行的 p1，这是回绕导致的顺序错误。
2. 从相同起点出发，每次只增加当前最小值，且增加量不超过 BigStride/2。若原有最大差满足该界，新值至多比旧最小值大这个界，因此最大差仍不超过它。这个推理针对题目给定的持续参与调度的进程集合。
3. 若差值小于半个整数周期，可用带符号的回绕差判断先后。BinaryHeap 默认弹出最大项，因此需要反转自然顺序，使较小 stride 在堆中具有较高优先级：

```rust
fn partial_cmp(&self, other: &Self) -> Option<core::cmp::Ordering> {
    let delta = self.0.wrapping_sub(other.0) as i64;
    Some(0i64.cmp(&delta))
}
```

这里遵从题设“不相等且跨度小于半周期”的前提。实际调度使用 u128 保存 stride，顺序扫描就绪队列；没有依赖普通 u8/u64 回绕比较。
